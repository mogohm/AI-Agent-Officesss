# DEPARTMENT_CHARACTER_PROMPTS.md
Base worker prompt for department character masters/states. Prepend this; the
per-character identity + pose go in each task's `prompt_suffix`. 256×384,
transparent, feet bottom-center, same world/style as the approved IT/Dev workers.

## Base character
```
cute detailed pixel-art human office worker, 3/4 top-down isometric view matching
the approved office floors, natural human proportions (not oversized-head chibi,
not realistic, not anime, not vector, not emoji), clean readable silhouette, thin
selective outlines, 3-tone shading with soft ambient occlusion, warm key light
from the upper-left. Single standalone full-body character, centered, feet at the
bottom-center anchor, nothing cropped, fully transparent background — no room, no
floor, no furniture, no shadow plate, no scenery, no UI, no text, no logo, no
watermark. Same art style and world as the provided approved worker and floor
references so this person clearly belongs in that building.
```
